Đề cương ôn tập giữa kỳ môn Khai phá và phân tích dữ liệu AIT3003

  1. Course introduction: data analysis and mining concepts.
  2. Data understanding: tìm hiểu dữ liệu của bạn, thống kê mô tả dữ liệu, mối quan hệ trong dữ liệu.
  3. Data preprocessing and preparation: làm sạch dữ liệu, biến đổi dữ liệu, giảm chiều dữ liệu, lấy mẫu dữ liệu.
  4. Distance and similarity: introduction, similarity measures for numeric vectors, similarity measures for data distributions, similarity measures for sets, similarity measures for sequence data
  5. Data clustering: hiểu dữ liệu trước khi phân cụm, phân cụm phân vùng, phân cụm theo mật độ.
